# 1:1 문의 페이지 스펙

1. 헤더
    - [x] 왼쪽에는 뒤로가기 버튼 (mypage로)
    - [x] 가운데 제목
    - [x] 오른쪽 아무것도 없음

2. 내부 헤더
    - 이메일 및 기타 공지사항
        - [x] 이메일 주소를 직접 누르면, 이메일 어플로 넘어가고,
        - [x] Copy 버튼을 누르면, 이메일 주소를 복사한다
    - [x] 문의하기 버튼
        - Form에 대한 구체적인 로직은 아래 4번 참고

3. 문의 목록
    - [x] 없으면, 문의내역이 없습니다.
    - 있으면,
        - [x] 구분과 제목, 그리고 상태를 표시
        - [x] 누르면 상세 페이지로 이동

4. 새 문의 생성
    - [x] 내부 헤더 안에 Form 버튼을 누르면 Form이 나타난다.
    - 유저가 Form을 작성하고 제출
        - 고객정보
            - [x] 로그인한 유저의 경우 자동으로 채워지고
            - [ ] 추후, 로그인한 유저도 익명으로 문의할 수 있도록 허용
            - [ ] 그렇지 않은 경우 직접 입력한다.
        - [x] 질문 구분은 menu select하도록 하고,
        - [x] 제목과 내용을 입력하도록 한다.
        - [x] 등록 버튼은 개인정보 수집 및 이용 동의를 체크해야 활성화된다.
    - 등록에 성공하면,
        - [x] 로그인한 유저의 경우, 리스트에 곧바로 반영
        - [x] 비로그인 유저의 경우, alert를 띄운다.
    - [x] 등록에 실패하면, alert를 띄운다.
    - [ ] 비로그인 유저들에게도 문의가 가능하도록 업데이트
