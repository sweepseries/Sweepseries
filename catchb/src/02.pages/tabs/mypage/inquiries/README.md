# 1:1 문의 페이지 스펙

1. 헤더
    - [ ] 왼쪽에는 뒤로가기 버튼 (mypage로)
    - [ ] 가운데 제목
    - [ ] 오른쪽 아무것도 없음

2. 내부 헤더
    - [ ] 전화번호, 이메일 및 기타 공지사항
    - [ ] 문의하기 버튼 -> 누르면 form이 나타난다
        - [ ] Form은 피그마 참고
        - [ ] 추후 비로그인 유저들에게도 문의가 가능하도록 업데이트

3. 목록
    - [ ] 없으면, 문의내역이 없습니다.
    - 있으면,
        - [ ] 구분과 제목, 그리고 상태를 표시
        - [ ] 누르면 상세 페이지로 이동
