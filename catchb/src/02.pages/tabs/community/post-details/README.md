# 커뮤니티 게시글 상세 조회 페이지 스펙

1. 헤더
    - [x] 왼쪽에 뒤로가기 버튼

2. 게시글 상세 내용
    - [x] 태그
    - [x] 작성자 프로필 + timesince(등록날짜)
    - [ ] 오른쪽에 메뉴
        - 내가 쓴 글이 아닌 경우:
            - [ ] 신고하기 -> 신고 모달창 띄우기
            - [ ] 차단하기 -> 모달로 확인 승인 시 차단 요청
        - 내가 쓴 글일 경우:
            - [ ] 수정하기 -> 수정모드로 전환
            - [ ] 삭제하기 - > 모달로 확인 승인 시 삭제 요청
    - [x] 제목
    - [x] 내용
    - [x] 이미지가 있으면 이미지 표시
    - [x] 조회수
    - [ ] 좋아요 수 표기 (누르면 좋아요)
    - [ ] 댓글 목록 표시 (자세한 내용은 아래)

3. 댓글 목록 컴포넌트
    - [ ] 댓글 작성자 프로필 (이미지 + 닉네임)
    - [ ] 오른쪽에 메뉴
        - [ ] 내가 쓴 댓글인 경우:
            - [ ] 신고하기
            - [ ] 차단하기
        - [ ] 내가 쓴 글일 경우:
            - [ ] 수정하기
            - [ ] 삭제하기
    - [ ] 내용
    - [ ] timesince(등록날짜) + 좋아요 수
    - [ ] 답글 달기 버튼
    - [ ] 답글 있을 시, 답글 목록

4. 최하단에 댓글 입력창
    - [ ] 입력창 + 전송 버튼
