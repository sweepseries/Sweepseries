# 커뮤니티 스펙

1. 헤더
    - [ ] 왼쪽에는 로고
    - [ ] 오른쪽에는 프로필 (누르면 변경 가능)

2. 하위에는 Top Tabs
    - [ ] Tabs는: 덕아웃, 드래프트, 마켓

3. 각 Tab 아래에는
    - [ ] 검색바
    - [ ] Sort
    - [ ] Filter bar (태그)

4. 그 아래에는 커뮤니티 글 list가 표시된다.
    - [ ] 글을 누르면 Detail Page로 이동
    - 기본적으로 표시할 기능
        - [ ] 이미지가 있으면 이미지 표시,
        - [ ] 글 제목 + 태그
        - [ ] 글 내용 일부 + 등록 날짜
        - [ ] 글쓴이 프로필
        - [ ] 조회, 좋아요, 댓글 수

5. 글쓰기 Floating Button이 우하단에 있다
    - [ ] 누르면 Create Post화면으로 이동
