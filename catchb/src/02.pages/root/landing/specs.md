# 시작 페이지 스펙

1-1. 네이버 로그인
    - 네이버 로그인 모듈을 통해, 로그인 시도하고,
        - 성공하면, 토큰을 가지고 프로필을 조회한다, 있으면 곧바로, 없으면 로그인 요청 후
            - [x] 성공하면 1-3. 소셜 로그인으로
            - [x] 실패하면 alert를 띄운다
    - [x] 실패하면 alert를 띄운다

1-2. 카카오 로그인
    - 카카오 로그인이 이미 되어있는지 확인을 한다
        - 이미 로그인되어 있다면, 프로필을 조회한다
            - [x] 성공한다면, 조회된 프로필을 가지고 1-3. 소셜 로그인으로,
            - [x] 실패한다면, alert를 띄운다
        - 그렇지 않다면, 로그인을 요청한다
            - [x] 로그인 성공하면, 위의 과정으로 넘어간다 (프로필 조회)
            - [x] 로그인 실패하면, alert를 띄운다

1-3. 소셜 로그인 (캐치비 서버)
    - 로그인을 요청하고, 결과가:
        - [x] 성공적으로 반환되면, 로그인 처리하고 home으로 이동
        - [x] 서버에 유저 정보가 없다면, signup으로 이동
        - [x] 로그인에 실패한다면, alert를 띄운다
