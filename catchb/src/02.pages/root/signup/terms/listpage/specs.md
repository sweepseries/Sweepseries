# 약관 목록 페이지

1. 서버로부터 약관 목록을 가져온다.  
   - [x] 약관 목록을 가져오는 동안 로딩 화면을 보여준다. (terms는 로딩 중에 undefined)  
   - [x] 약관 목록을 가져오지 못하면 오류 메시지를 보여주고 이전 페이지로 돌아간다  

2. 약관 목록을 화면에 보여준다  
   - [x] 내용이 있으면 상세 페이지로 이동할 수 있는 버튼을 보여주고, 그렇지 않으면 버튼이 없다.  
   - [x] 약관을 누르면 check를 토글하고
   - [x] 약관의 오른쪽 화살표를 누르면 상세 페이지로 이동한다.  
   - [x] ‘모두 동의합니다’를 누르면, 모든 약관이 체크되어 있으면 모두 체크 해제하고, 아니면 모두 체크한다.  
   - [x] 필수 약관이 모두 체크되어 있어야 다음 버튼이 활성화된다.  
   - [x] 다음 버튼을 누르면, catchb 모드일 시 아이디/이메일 입력 페이지로 이동하고,
   - [x] 그렇지 않으면 전화번호 인증 페이지로 이동한다.
