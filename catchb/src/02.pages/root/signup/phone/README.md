# 이름 입력 & 전화번호 인증 페이지 스펙

1. 이름 입력
    - [x] 캐치비 모드이거나 카카오 모드일 경우, 유저에게 직접 입력을 받아야 한다
    - [x] 네이버 모드일 경우, 무조건 네이버로부터 이름 입력이 들어온다. 수정을 허용

2. 전화번호 인증
    - [x] 입력은 유저에게 직접 받아야 한다. 앞 번호는 무조건 010이고, 가운데와 끝자리 입력을 받는다.
    - 입력 필드 오른쪽에 [인증번호 받기] 버튼이 있다.
        - [x] 가운데와 끝자리에 각각 4자리씩 입력이 들어와야만 이 버튼이 활성화 되며
        - [x] 이 버튼을 누르면, 3분 카운트다운이 시작되고, 버튼이 비활성화 되며, 버튼 텍스트가 타이머로 기능한다.
        - [x] 3분이 지나면, 다시 버튼이 활성화된다.
    - 인증번호가 전송이 되면,
        - [x] 아래쪽에 인증번호 입력 필드와 인증하기 버튼이 생기며
        - [x] 3분 안에 인증번호를 입력해야 하고
        - [x] 인증하기 버튼은 6자리를 입력해야지만 활성화된다.
    - 인증번호를 입력하고 인증하기 버튼을 누르면, 서버에 확인 요청을 한다.
        - [x] 성공하면, 인증번호 받기 버튼과 인증하기 버튼이 비활성화 되며,
        - [x] 회원가입 버튼이 활성화된다.
